# Sicherheit

Bitte Sicherheitslücken **nicht** als öffentliches Issue melden, sondern per E-Mail an info(at)leyonet.ch, am besten mit Version, Ablauf und
möglicher Auswirkung.

Unterstützt wird die jeweils neueste Version. Aufbau, Datenhaltung und Löschfristen des Servers: [docs/ADMIN_SERVER.md](docs/ADMIN_SERVER.md).

Bekannte Grenze, kein Fehler: Das Spiel läuft im Browser und ist quelloffen. Der Zugangscode fürs freie Bauen ist eine Schranke, kein Schutz
gegen veränderte Fassungen.
